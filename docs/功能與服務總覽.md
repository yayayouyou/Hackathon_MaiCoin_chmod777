# MAIA 功能、Skill 與串接服務總覽

> 盤點日期:2026-09-24。「狀態」欄是**本機實測**結果 ——
> 用 `agent-core/scripts/skill_healthcheck.py` 逐一實際呼叫每個工具,外部服務用真實請求打過一次。
> 怎麼啟動請看 [README「怎麼跑」](../README.md#怎麼跑)。

**一句話**:MAIA 是一個可以走進去的像素風 2D 世界,裡面有一位會自己挑工具的 AI 助理(113 個工具),
串接 MAX 交易所與二十多個市場資料來源;需要下單時它**只能提議**,由人按確認才會執行。

## 1. 系統全貌

```
瀏覽器
 ├─ 像素世界 localhost:3000(frontend-pixel,Vite + React 19 + Canvas)
 │     └─ /api/* ──Vite proxy──┐
 └─ 內建對話頁 localhost:8000/ ─┤(後端直接送 templates/index.html)
                                ▼
                 後端 agent-core(FastAPI,localhost:8000)
                  ├─ /api/chat(SSE)→ MAIA 大腦(ReAct 迴圈)
                  │     ├─ LLM:OpenRouter(google/gemini-2.5-flash)
                  │     └─ 113 個工具 → MAX / Binance / CoinGlass / SoSoValue …
                  ├─ 帳戶、持倉、掛單、撤單 API → MAX 私有 API(HMAC 自簽)
                  ├─ 登入 / 玩家資料 → DynamoDB(本機:Docker 的 DynamoDB Local :8001)
                  └─ 背景執行緒:策略機器人 runner(paper)、Telegram polling(目前暫停)
```

| 元件 | 位置 | 技術 |
|---|---|---|
| 像素世界前端 | `frontend-pixel/` | Vite 7 + React 19 + 原生 Canvas 60fps;runtime 相依只有 react / react-dom |
| 後端 API | `agent-core/agent_ui/app.py` | FastAPI(約 50 條路由),同時提供內建對話頁與行為分析頁 |
| MAIA 大腦 | `agent-core/agent/` | 手寫 ReAct 迴圈、三供應商 LLM 抽象層(OpenRouter / Bedrock / Ollama) |
| 工具(skill) | `agent-core/skills/` | 9 大類,另有 5 個 agent 內建工具 |
| 部署設定 | `agent-core/deploy/` | CloudFront + ECS Fargate + AgentCore Runtime(黑客松時用,目前已下線) |

## 2. 使用者看得到的功能

### 2.1 像素世界(3 個區域)

| 區域 | 內容 |
|---|---|
| **數位廣場 · 大廳** | 主場景。MAIA 對話點、現貨交易、MAX 官方消息 / 活動、我的金庫、交易性格、損益對帳、討論區入口 |
| **交易者公會** | 熱門排行、策略牆 |
| **討論室** | 從討論區選一間走進去,看貼文、留言、同步 Threads 討論 |

操作:`WASD` / 方向鍵移動、`E` 互動、`Enter` 開 MAIA、`Tab` 快捷格、`/` 命令面板、`Z` 全景 / 跟隨。
點底部功能條會「傳送 → 角色自己走過去 → 自動打開」。

### 2.4 登入

- 帳號 / session 存 DynamoDB;本機用 Docker 的 DynamoDB Local。
- `agent-core/.env` 設 `MAIA_LOCAL_NO_LOGIN=1` 時,**從本機連進來**的請求可直接用對話、帳戶、掛單、撤單;
  發文、進度、官方操作仍要登入。部署環境帶轉發標頭,一律要登入。

## 3. MAIA 大腦怎麼運作

```
使用者問題
  → 人格判斷(6 種,自動挑)
  → 工具路由:關鍵字比對 → 沒命中再用 embedding 語意檢索 → 依信心挑 9~62 個候選工具
  → ReAct 迴圈(最多 8 步;每步可同時呼叫多個工具)
       └─ 外部內容先過 Reader Agent 淨化(防 prompt injection)
  → 下單類工具不直接執行 → 產生「待核准」計畫 → 人按確認 → 再過四道實盤防線
  → 若是買賣 / 多空建議,Critic 再審一次 → 回覆 + 圖表卡片 + 依據來源
```

| 機制 | 做什麼 | 位置 | 狀態 |
|---|---|---|---|
| ReAct 迴圈 | 最多 8 步、原生 function calling,SSE 串流每一步 | `agent/ollama_agent.py` | ✅ |
| LLM 抽象層 | OpenRouter / Bedrock / Ollama 共用同一介面,`.env` 一行切換 | `agent/llm/` | ✅ OpenRouter(回覆不逐字串流) |
| 工具路由 | 關鍵字 → embedding(bge-m3 via 本機 Ollama) | `agent/tool_router.py`、`tool_embeddings.py` | ⚠️ 本機沒跑 Ollama → 只用關鍵字(自動降級,不會壞) |
| 6 種人格 | AI 加密分析師、新手小白教練、巴菲特、達利歐、李佛摩、鏈上巨鯨追蹤者 | `agent/personas.py` | ✅ |
| Reader Agent | 新聞 / 社群等不可信內容先遮蔽 + 摘要再給模型 | `agent/reader_agent.py` | ✅ |
| Critic | 只在「真正的買賣 / 多空建議」時啟動,審推理邏輯;沒過就附上風險警示與審查意見 | `agent/critic_agent.py` | ✅ |
| 交易核准互鎖(HITL) | 下單計畫 SHA256 凍結、120 秒 TTL、人按確認才執行 | `agent/trade_approval.py` | ✅ |
| 四道實盤防線 | kill switch 檔案、`LIVE_UNTIL` 授權到期、24h 曝險上限、決策台帳 | `skills/execution/live_guard.py` | ✅(授權 8/5 已過期 → 自動模擬盤) |
| 審計日誌 | 每輪決策 SHA256 鏈式紀錄 | `agent/audit_logger.py` | ✅ |
| 分層記憶 | 記住 / 回想 / 忘記使用者偏好 | `agent/memory_store.py` | ✅ |
| 分析沙盒 | 模型臨場寫 Python 分析(Code-as-Action) | `analyst_sandbox/` | ❌ Windows 不支援(`pass_fds`),Linux 才能用 |
| 策略機器人 | 策略打包成 paper 機器人,背景 runner 定期評估並模擬成交 | `agent/strategy_bots.py` | ✅ |
| 社群摘要 | 用 LLM 把當日討論室貼文整理成摘要 | `agent_ui/community_insights.py` | ⚪ 可用,今天還沒產生 |
