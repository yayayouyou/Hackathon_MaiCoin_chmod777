### S1 · 封面
- **內容**:產品名 MAIA + Logo · 一句話定位 · 團隊名 · 「MaiCoin × AWS 黑客松」
- **視覺**:深色金融科技風,一句話定位放最大

### S2 · 痛點(商業 20%)
- **三個破碎**:①資訊過載(鏈上數據/指標/訊號判讀門檻高)②訊號到下單流程斷裂 ③工具只會「呈現」不會「主動」
- **數據佐證(用我們跑的真實分析當鉤子)**:
  > 「我們分析了一位真實用戶一年 10,000 筆交易,發現他的**買入均價幾乎等於賣出均價**(BTC 買 344.3萬 vs 賣 344.4萬)——**散戶的交易時機對價格幾乎沒有 alpha,本質是隨機噪音**。這正是為什麼投資人需要的不是更多圖表,而是一個有紀律、能主動提醒的 AI。」
- **講稿重點**:把「散戶交易 ≈ 隨機」變成產品存在的理由,一句話立住 thesis

### S5 · 支柱一:交易 DNA 洞察(創意主武器)⭐
- **核心創意**:加密版「Spotify Wrapped + 性格報告卡」
- **行為指紋維度**:交易頻率 · 平均持有時長 · 追高殺低偵測(FOMO/panic)· 過度交易 · 持倉集中度 · 風險偏好
- **真實數字素材(可直接上圖)**:
  - 全年 10,000 筆、平均每月 ~830 筆(高頻交易者畫像)
  - 期末加密資產估值 **≈ 163 萬 TWD**:ETH 40.5萬 · USDT 44.5萬 · DOGE 32.7萬 · USDC 26.4萬 · BTC 10.2萬 · SOL 9.5萬
  - 7 幣種資產配置圓餅圖
- **講稿**:「我們不只給你看數字,我們告訴你『你是什麼樣的交易者』——並生成一張你會想分享的年度報告卡。」(病毒行銷鉤子)

### S6 · 支柱二:Grounded AI 特助(AI設計主武器)⭐
- **差異化**:財務 AI 最大恐懼是**幻覺亂建議** → MAIA **每個回答都掛數字/來源引用**
- **示範對話**:
  - Q:「我今年 ETH 賺賠多少?」→ A 呼叫分析引擎算 **FIFO 已實現/未實現損益**,附計算依據
  - Q:「現在該加碼 BTC 嗎?」→ A 即時呼叫 **MAX API 抓現價/K線**,結合你的持倉與風險偏好回答
- **能力標註**:上下文理解 · 工具調用(Tool Use)· 主動分析 · 防幻覺(數字皆有來源)
- **主動預警範例**:「你的 DOGE 部位佔比已達歷史高點,且突破月高,要不要部分獲利了結?」

### S7 · 支柱三:對話式下單閉環(商業主武器)⭐
- **閉環流程**:提問 → AI 策略分析 → **人類守門確認(human-in-the-loop)** → 呼叫 MAX Skill 下單 → **事後歸因回饋**
- **安全設計(直接對應「技術可行性」要的限制說明)**:部位上限 · Paper-trade 模擬模式 · 明確二次確認 · 費用/滑點揭露
- **自我進化飛輪**:每筆交易的歸因結果回饋更新用戶行為模型 → 建議越來越個人化
- **視覺**:閉環流程圖(強調「守門」與「回饋」兩個別人不會做的環節)

### S8 · 殺手橋段:反事實回測(創意 + 商業高潮)⭐⭐
- **一句話**:「如果你今年照 MAIA 的紀律策略走,會多賺多少?」
- **做法**:用 CSV 回測「用戶真實決策 vs AI 紀律策略」,把產品價值**量化成一個具體數字**(例:+X%)
- **講稿**:demo 的情緒高潮,直接證明「MAIA 值多少錢」
- **備註**:回測方法需誠實揭露假設(避免過擬合質疑),這也是加分的嚴謹度

### S9 · AI 技術應用(交付②· AI設計 15% · 主題 10%)
- **多代理分工(supervisor)**:Orchestrator 委派 Market-Research / Portfolio-Analysis / Risk / Execution 四個 worker
- **框架/大腦**:**Strands Agents SDK on Amazon Bedrock**;Claude 當推理腦、Amazon Nova 當廉價確定性子任務
- **行動**:Bedrock Converse API 工具調用(ReAct 迴圈),工具以 MCP 註冊:分析引擎 / MAX 行情 / Web 搜尋 / MAX 下單
- **主動性**:EventBridge 排程觸發 Lambda 主動盯盤預警
- **防幻覺策略**:Grounding Contract(數字只出自工具、每個數字掛來源)+ **Bedrock Guardrails**(擋理財建議/PII/Contextual Grounding Check)+ 結構化輸出
- **可觀測**:CloudWatch / AgentCore Observability 呈現推理鏈給評審看
- *(詳見 `docs/架構與實作計畫.md`)*

### S10 · 數據資料應用(交付③· 主題 10%)

### S12 · AWS 架構圖(交付⑤· 技術可行性 20% · 主題 10%)⭐
```
前端 Next.js → Amplify Hosting (CloudFront) + Cognito
        │  HTTPS + SSE 逐字串流
App Runner ── FastAPI + Strands Agents (可選上 AgentCore Runtime)
   🧭 Orchestrator (Bedrock Claude)
     ├ 🔎 Market-Research (Web/News/情緒)   ├ 📊 Portfolio-Analysis (Nova, 包 Python 引擎)
     ├ 🛡️ Risk/Guardrail (Cedar Policy)     └ ⚡ Execution (唯一持 MAX private key)
   工具(MCP): 分析引擎 / MAX 行情+下單 / 第三方(CoinGecko·Coinbase·RSS,短TTL快取)
   防護: Bedrock Guardrails · Secrets Manager · HITL 確認閘
主動代理: EventBridge Scheduler → Lambda → SES/SNS 預警
資料/觀測: DynamoDB(記憶/watchlist) · S3(CSV/報告) · CloudWatch
```
- **標註**:強調 **多代理 agentic + Bedrock + MAX + HITL 安全閘**;每個框都是真部署的 AWS 服務
